# DOCUMENTATION STANDARDS

## 1. Markdown Formatting
- **Line Length:** All markdown files (`.md`) should be hard-wrapped at 88 characters to ensure readability in all environments.
- **Headers:** Use ATX-style headers (`#`, `##`, etc.). Do not use Setext-style headers (headers underlined with `=` or `-`).
- **Lists:** Use `-` for unordered lists.
- **Emphasis:** Use `**bold**` for bold and `*italic*` for italics. Do not use `__` or `_`.
