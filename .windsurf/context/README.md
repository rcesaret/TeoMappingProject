# Context Directory

This directory stores high-level, foundational context about the project. This information is intended to be relatively static and provide a comprehensive overview for any developer or AI agent engaging with the repository.

## Files

-   **`product_requirement_docs.md`**: Product Requirement Document (PRD) or Standard Operating Procedure (SOP). Defines the project's purpose, problems it solves, core requirements, and goals. Serves as the foundational document and source of truth for project scope.
-   **`dev_architecture.md`**: A detailed description of the project's technical architecture, including component diagrams, data flow, and technology stack.
-   **`technical.md`**: Technical Specifications Document. Details the development environment, technologies used, key technical decisions, design patterns, and technical constraints.
-   **`glossary.md`**: A centralized dictionary of all project-specific terminology, acronyms, and domain concepts.
