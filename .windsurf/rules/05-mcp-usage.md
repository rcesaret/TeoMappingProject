# MCP USE
You **MUST** use the following MCP servers in the contexts specified below:
- Use `desktop-commander` for file system & directory operations, file operations (reading/writing/editing/processing), process management, command execution
- Use `memory` for knowledge management, context retention, storing & retrieving information
- Use `sequential-thinking`, `mcp-sequentialthinking-tools`, and/or `code-reasoning` for problem-solving, complex or multi-step tasks, step-by-step reasoning, & tasks involving large contexts
  - For code analysis, validation, debugging & optimization → `code-reasoning`
  - When coordinating multiple MCP tools and maintaining context across steps → `mcp-sequentialthinking-tools`
  - Otherwise → `sequential-thinking`
- Use `context7` for consulting official library/API documentation, code examples
- Use `fetcher` for web page content retrieval & processing
- Use `brave-search` for web searches & online research
- Use `github` for version control, git & repository operations
- Use `postgres` for database analysis, queries, health checks, performance analysis
- Use `excel` for analyzing, reading and writing `.xlsx` files
