# MCP USAGE
You **MUST** use the following MCP servers in the contexts specified below:
- `desktop-commander`: File/dir ops, file I/O, process/cmd/PS execution.
- `memory`: Knowledge/context mgmt, info storage/retrieval.
- For step-by-step reasoning, problem solving & complex, multi-step, and/or large-context tasks:
    - `code-reasoning`: Code analysis, validation, debug, optimization.
    - `mcp-sequentialthinking-tools`: Multi-tool coordination, cross-step context.
    - `sequential-thinking`: Otherwise.
- `context7`: Official lib/API docs & code examples.
- `fetcher`: Web page fetch/process.
- `brave-search`: Web search/research.
- `github`: Git, version control, repo ops.
- `postgres`: DB analysis, queries, health/performance checks.
- `excel`: Read/write/analyze `.xlsx` files.
